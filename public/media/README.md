# Vídeos locais (fallback)

Esta pasta está pronta para receber arquivos `.mp4` caso algum embed do Instagram/TikTok deixe de funcionar.

Os nomes esperados pelo projeto estão documentados em `src/data/portfolio.js` no campo `localFile`.
Você pode substituir/alterar os nomes à vontade.

Exemplo:

- `worldcel-reparo.mp4`
- `worldcel-redmi-note-14-pro.mp4`
- `worldcel-gravacao-laser.mp4`
- `brawl-news-01.mp4`
- `lgf-edit-01.mp4`

Evite subir vídeos muito pesados no próprio GitHub Pages. Para arquivos grandes, prefira YouTube/TikTok/Instagram ou um CDN.
